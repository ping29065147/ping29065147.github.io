# 劇本排名與心得

# 情感本排名：

  1. 《蒼岐2:青川》
    【離離月曙照清闕，靄靄山嵐入弈局】
    【寧叫秋光作別禮，不以三春長留君】
    作為蒼岐的續作，彩蛋與連動超級多，與蒼岐的聯合刀真的超痛
    目前哭最慘的一本，一刷從前中期就開始陸陸續續哭到結束
    文本寫得很好，很多文字都很戳心，也很深刻
    整體流程很新穎，能讓我全程很沉浸
    目前玩過三刷！越來越喜歡這本了

  • 一刷 - 軒轅禮
    柳清鵲真的是世界上最完美的公主殿下，她對阿禮真的很好
    開場是開開心心的金毛大狗狗，但前面多快樂，後面就有多痛
    仙品愛情，玩過的劇本中(157本)最喜歡的愛情線
    車友也都很貼角色，真的是體感非常好的一段人生

    【軒轅禮，整個青川，都在接你回家。】
    【清鵲，我很想妳】

  • 二刷 - 應長留
    換個身分，得知了另一邊的視角
    這次在不同店家玩，拉普的服裝與場景真的很美，很出片，二刷的體感同樣很好

    【妳拋不下那些人，就能拋下我嗎？神女殿下】

  • 三刷 - 離昭
    第一次反串，沒想到全線開花，在應長留沒吃到的愛情這次吃好吃滿
    真的很感謝車友與CP給我這麼好的體驗
    CP真的超級用心，準備了一大推東西與手寫信，而且時機都非常好，看到信我一秒落淚
    同時她也真的很應長留，是我心目中想像的樣子，常常會因為她的一舉一動而被感動

    【不可看，不可聽，不可說，要用心】
    【我許願，明天會是個晴天】

  1. 《竊雲台》
    【竊國為私，謂之為賊；竊國為公，謂之為君】
    高互動演繹的古風權謀情感本
    經過企鵝的改版後，整體流程變得很順暢、有趣，有些蠻意想不到的劇情發展
    全程都很精彩、很沉浸，沒有很拖沓的環節
    文本寫得非常好，文字有寫進心裡，能夠自我沉浸看本哭

  • 一刷 - 蘇月白
    我還蠻喜歡蘇月白的人設的，秉持文人風骨
    也很喜歡這本的愛情線，仙品愛情，超越青川的軒轅禮
    謝雨山真的太好了，我最後看到人就一直哭，直接登頂cp榜
    cp真的表現很好，過程中我們還一直傳紙條聊天、互動
    再加上前世的記憶，所以體感非常好

    【願如風有信，長與日俱中】
    【謝雨山，記得愛我，別讓我魂飛魄散】
    【雨山，不要在乎我的身後名，人間的罪孽困不住我。唯有妳的愛，可以將我化作囚徒，可殺可別，百無禁忌】
    【謝小姐，若是議親，煩請先考慮在下】
    【請雨山以餘生，鑑月白愛慕之心】
    【平生一顧，至此終生】
    【求之不得】

  • 二刷 - 朱懿珩
    其實朱懿珩才是比較貼我的人設
    親情的部分真的寫得很好，很感動
    但是愛情不是我會很喜歡的模樣，所以稍嫌可惜
    二刷的體感仍舊很好，真的是一本很值得玩的本

    【百合安神】

  1. 《九州四海入鏡來》
    【我以我身藏日月，陰陽可開，天地自來！】
    雖然是個還蠻舊的本，但我還蠻喜歡的，永遠的白月光，從此讓我愛上了情感本
    古風仙俠背景，描述了一整個江湖群像，每個角色都有血有肉，都有自己的個性、選擇與執念
    陸雲齊的親情、愛情、師徒、成長線全線開花，每條都吃好吃滿
    劇光燈出動了4位GM，很好的呈現出江湖熱鬧紛雜的氣氛

  2. 《燈影裡的烏有鄉》
    【他鄉縱有當頭月，不及家鄉一盞燈】
    第一本在吉米家玩的劇本，吉米的演繹真的很厲害，可以輕鬆的帶動玩家的情緒，沉浸到故事中
    民國背景的大親情本，能感受到身處時代洪流中的身不由己
    燈，是什麼？
    影，是什麼？
    烏有鄉，又是什麼呢？
    這是一個關於家、關於愛的故事，歡迎回家

  3. 《山崗上的長風》
    【八千卷苦竹難書，七情六慾讓五嶽山崗】
    【四萬萬功名塵土，三江兩海過萬里風長】
    《流氓敘事》作者的前一部作品，文字優美細膩
    吉米家改編加入了大量流氓的彩蛋，連動滿滿
    通過長篇的敘事、前期歡樂的機制拉滿了羈絆
    每位角色都沿著自己的人物弧光最後實現自己的高光

  4. 《河西家萬里》
    【河西萬里，往前走，莫回頭】
    我一直都很喜歡表裡山河系列，總會呈現希望玩家去思考的核心價值
    這是一部關於家族、土地、傳承、遷徙與歷史的立意情感本
    中間歡樂與機制的部分十分有趣，真的有大家一同共患難的感覺
    故事最後扣回標題，原來「家」這個字的意義，比想像中的還要重
    這本的GM剛好跟我《蟪蛄春秋》的GM一樣，沒想到會吃到小蜂的刀，哭死......

  5. 《黑貓3:他從東方來》
    【前方靠岸，法蘭西北部，黑貓士兵們，該下船了】
    擁有超大群像的民國親情本
    群像描寫的很生動、活靈活現，一個個都是鮮活的個體，每一個紙片人我都哭慘了
    我擁有最好的哥哥，第一次在一個劇本中羈絆被拉得這麼滿 (甚至哥哥的cp都說忌妒我了)
    開場我就覺得不太妙，果然後面整個人破破爛爛，看本也一直流淚

  6. 《紅豆》
    【離開家後的每一步路，都是歸途】
    民國親情本，同樣在寫【家】的故事
    這本本來我應該會去霜降，被調劑去了芒種，但最後也是破破爛爛
    文本量不多，但用字溫柔優美，看本就可以流淚，最後一本我看了三遍，哭了三遍
    與gm fs的部分真的很感動，萊茵真的很厲害！能輕易的把一個人刀到流淚
    結束後我還獨自在哭，不能自已

  7. 《山楂林終:紅梅花下》
    【山楂林里，萬物永不褪色】
    【紅梅花下，你我速朽方生】
    開本第一幕眼眶就濕了，作為馬塞，連動太痛了，文本中滿滿的刀子
    看似圓滿的故事卻又不太圓滿
    秦、秦陽，似是而非，我好像在她身上看到過去的影子

  8. 《如故》
    【池魚籠鳥、自憐自哀、心如死灰。
    求之不得、恨海難填、慧極必傷。
    你瞧，人總是從一開始就被定了性、定了命。
    我曾問過他們，若是如此他們為什麼還要活著？
    他們說，從來都沒有所謂的命中註定。
    這一生的經歷與相逢，是他們機關算盡、絞盡腦汁強求來的。
    所以他們，原諒覺得不甘心、恨下去又覺得痛苦、放下又做不到。
    他們要纏在一起，緊緊纏繞在一起，就算緊到相看兩厭也要掐著對方的脖子說：好啊，黃泉相見。
    但當璧陰倒轉、時間重回，才發現他們還是，相思如故。】
    第一次玩12小時的古風情感本，整體流程其實都還蠻緊湊且有趣的
    算是比較特別類型的情感本，人均高光，每個人都有大輸出、大演繹的部分
    文本的字句寫得很不錯，古典又不會文言，有些句子很戳人，能夠看本哭
    劇情與文本稍微有些複雜，所以蠻需要理解能力的
    雖然玩之前被打了很多預防針，說我可能不太適合，不太會喜歡這個本，但實際玩完其實還蠻喜歡的
    我也非常喜歡我的角色-李文瑙
    兄弟線真的寫得很好，而且不單是一種簡單的情感，多種複雜的情緒交織
    愛情線雖然著墨的不多，但同樣描繪得非常好

    【此岸為生滅，彼岸為不滅的涅槃。以至往生，天命開口，諸君當從此岸走向彼岸，去向輪迴。十年五載，兩世流離，相思如故】

  9. 《蟪蛄春秋》
    【朝菌不知晦朔，蟪蛄不知春秋】
    山楂林作者的續作，題材與設定很有意思，有些科幻+奇幻的要素
    而且這本沒有性別之分，每個人都是蟲蟲
    過程中的環節算是蠻常見的，但也有有趣的地方
    只可惜有些賣弄文采，導致文字沒那麼深刻

    【蒼山多岐路，誰識少年心】
    一刷的時候是蕭原，體感普通
    二刷的時候是軒轅靈澈，體感超好
    多虧了超卷的車友，準備了超多東西，又被刀爛
    打之前沒有想過會哭，結果是哭最慘的一個

  2. 《永不褪色的山楂林》
    【山楂林裡，萬物永不褪色，永遠年輕】
    【秦陽，你站在這裡，這是我的人間】
    很特別的一個劇本，印象深刻

    有一些很新奇的體驗
    真的很開心能作為馬塞玩這個劇本

  3. 《舊賦》
    【舊賦流傳，盡數千年...】
    雖然已經是3年前的本了，但我還是蠻喜歡舊賦的故事，
    在現在這個瘋本橫行的時代中，偶爾體驗不太一樣的情感也十分感動，
    劇情的走向偏老套，但仍有沒有猜到的部分，刀子很多、很難過。
    原裝好像是6小時內結束的本，我們玩了8小時左右，
    主持人帶本的節奏掌控的很好，時間雖長，但每個流程都不拖沓、很沉浸，
    也有加入自己的一些小巧思，很驚喜。
    這邊要特別誇獎一下小白(阿辰)，聽說她是第一次當戀陪位，就表現的超級超級好，
    不論是演技還是互動都很不錯，尤其是葉奕秋的體感基本上就是取決於小白的表現了。

    【聽！海螺裡有南風的聲音】
    【6...1...2...思南風】

  5. 《萬仞青山聽水寒》
    【大丈夫立與天地之間，當養浩然正氣，行光明磊落之事，克己，慎獨，守心，明信】
    九州的續作，彩蛋滿滿
    群像仍寫得很好，紙片人的故事令人動容
    能近一步更了解了整體的世界觀，九州四海到底發生了什麼事，也為下一部「花」做好了鋪墊
    劇情沒有前作那麼精彩，但是角色我仍然很喜歡

# 推理本排名：

  1. 《來解決一切的名偵探也死了》
    我的第三本劇本，也是第一本長時推理本，推理本中的白月光
    第一次挑戰長時本就玩了快10個小時，卻也不覺得累
    過程中的反轉直接讓我開啟新世界，原來劇本殺還可以這樣寫?!
    無論是兇案的反轉、故事的反轉都意想不到，尤其是最後故事的收尾我非常喜歡!

  2. 《因火成煙》
    若撇除白月光的存在的話，這本是目前玩到最好玩的推理本
    設定層層遞進、層層堆疊，卻又巧妙的嵌合在一起
    世界觀十分有趣，看似荒唐卻又十分合理
    極致的果推因，瘋狂的反轉，設定與故事完美結合，有微情感也可以吃瓜
    核詭真的太巧妙了，盤出來時真的很驚艷

  3. 《安美納斯DE死亡推想o》
    另一本讓我非常驚豔的推理本
    在其他本可以當成核詭的詭計，一次出現了好幾個
    無論案件、設定與反轉都與其他推理本有非常巨大的不同，全程都十分驚喜
    再加上有實體模型的加持，可以動手實際操作

  4. 《未有來時》
    整本的設定推理都很有趣，我很喜歡他的案件
    設定繁多，但都不難理解，有些設定貫穿全本，很精彩
    角色故事的文本寫得很好，很像情感本
    莫名的有吃到一些情感本深刻的點
    整體的故事與結尾的餘韻也很舒服

  5. 《雀色蟬時雨》
    第一本讓我哭的推理本，劇情寫得很感動
    劇本本身的謎題難度適中，角色故事塑造得很好
    如果接在作者前一部作品《戀路十六夜》之後玩感觸會更深
    真的是沉浸於故事中才會作出的選擇

  6. 《關於Y的奇蹟》
    其中一案最譽為2025年最強單案，果然名不虛傳，超級精彩，盤案的時候驚呼連連
    故事也是我非常喜歡的風格，走一個日式溫馨治癒的風格

# 恐怖本排名：

  1. 《鈴蘭女校2:富江花子》
    很精彩的一本恐怖本
    恐搜的形式不單是簡單的搜查，有做出不同的機制，十分有趣
    中間撲朔迷離的劇情發展更是在無形中增加了心理壓力
    無論恐怖氛圍的營造、劇本整體流程、兇案、反轉與故事我都很喜歡
    福爾謀殺寬敞與大量的房間更是增加了沉浸感與刺激感

  2. 《崇山樂園1》
    崇山系列的第一本，算是比較早期的東京恐怖故事系列
    故事還蠻清楚的，同時有埋下一些伏筆
    最後結束的稍為有一點突然

  3. 《崇山樂園2:小丑回魂》
    身為東京恐怖故事系列，卻是以「小丑」為主軸的本
    走的是美式恐怖，比較沒有鈴蘭系列詭譎的氣氛
    整體流程還行，但是體感偏短
    優點是出動了很多npc，演繹還蠻精彩的

# 機制陣營本排名：

  1. 《白衣傾城》
    古風題材的機制、情感、陣營本，文字典雅優美
    有大量的私聊環節，自由度極高
    無論喜歡談戀愛、玩機制、推理兇案、還原故事，都能找到屬於自己的快樂

雖然很荒謬，但魏大勇很快樂的在談戀愛，好愛喔

  1. 《青山雲海》
    白衣傾城的前傳，同為古風題材的機制、情感、陣營本，文字也同樣典雅優美
    與前傳截然不同的機制，隨著機制逐漸推進劇情
    這本仍維持系列一直以來自由度極高的傳統
    也讓人期待這個龐大的世界觀，《紅顏易老》會怎麼收尾

  2. 《獨家古惑仔》
    港風機制陣營本
    全程的遊戲都很好玩，超級歡樂

心好痛。

我總會回想起我們一起賞並蒂蓮的池塘，池中的蓮花盛開嬌豔，卻再也沒有那比花更美的倒影了。

我不在。

我也不在。

把妳從路克斯帶到奧普斯後，妳以為是我救贖了妳。

不，其實是妳救贖了我。

我很小的時候就失去了雙親，與妹妹相依為命，當時只想著把一切的好都給她，但是加入路克斯後，卻把她帶到了另一個深淵，我沒辦法回家陪她，我的上司也一直利用她威脅我。

但是妳，像一道光一樣走進了我的生命。

我的志向是成為一名「救死扶傷」的醫生，但是加入那兩個組織之後，我不是在抹滅人的靈魂，就是在殺死人的肉體，我好像離我當初的目標越來越遠了。

所以那段時間，我其實很自我懷疑。

是妳教會了我什麼是愛。

是妳治癒了我。

從那次的煙火大會之後，妳好像在我心中有了一個位置。

那是第一次，有一個人對我這麼好。

我真的很享受與妳一同經歷的那些時光，那是我這一生中最快樂的日子了。

如果可以的話，我好想要拋棄這一切，拋棄所有身份，跟妳遠走高飛，或去哪都好。

可惜這個世界上沒有如果，毒藥已經進入了我的身體。

40秒的時間，足夠溫一碗杏仁奶，但不夠我把想說的話都說給妳聽。

我其實還有好多好多的話想對妳說，但是我已經說不出口了。

原來，聽覺被剝奪的世界是這麼的安靜。

安靜到，連自己的心跳聲都聽不見。

傳說中人死後會化作天上的星星，在天上看著世間的人，妳若想我了，就看一看天空吧。

視線之外，我一直在。

時間差不多到了，我該走了。

四月，我喜歡妳。
